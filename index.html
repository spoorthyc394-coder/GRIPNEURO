EMG Interpretation

The EMG sensor measures electrical activity produced by muscles during rehabilitation. The dashboard receives the signal from Arduino and displays it as a real-time waveform.

Higher variations in the waveform indicate changes in muscle activity. The collected values can be used to observe muscle engagement during different hand exercises.
